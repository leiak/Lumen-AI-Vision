库门口异常停留识别系统

让连续视频变成
可处理、可解释、可闭环的风险事件

系统不是把视频转发到云端，也不是只做一个报警弹窗，而是把“车辆进入关键区域—停留超时—行为变化—风险判断—人工处理—样本回流”连成一条完整业务链。

端边云三级协同架构
小模型 + VL初筛加语义解释
人工复核结果回流持续优化
当车辆在库门口关键区域停留超过业务允许时间，且出现需要关注的状态变化时，系统自动生成风险事件，并推动安保、仓储和调度人员在规定时间内完成确认与处理。
不是回看系统重点在实时发现与处理闭环，而不是事后找录像。
不是车辆计数重点在停留时长、区域、行为状态和风险等级。
不是盲目上云边缘先过滤，云端只处理关键帧和疑似事件。
不是黑盒告警每个事件都有关键帧、模型结果和中文解释。

八步主流程

从车辆出现到事件关闭，每一步都有明确的输入、判断和产出。

1

车辆进入

YOLOv8n 检测车辆，车辆轨迹与预定义库门口区域求交。

2

停留计时

轨迹中心点持续落在区域内且满足静止条件，系统启动计时。

3

状态观察

持续观察移动、驶离、车门、人员上下车等状态变化，容忍短时丢帧。

4

关键帧抽取

只抽取进入、静止、状态变化、超时、驶离等高价值帧。

5

候选事件

超过停留阈值或出现高价值状态变化时，边缘生成事件候选。

6

云端判定

轻量时空模型结合时长与状态初筛，系统完成去重与风险分级。

7

解释与复核

VL 生成中文行为描述，中高风险进入复核任务和通知。

8

处理与回流

处理结果关闭事件，复核结果沉淀为训练样本和运营指标。

事件状态机

事件必须能从候选推进到终态，不能永远停留在待处理列表里。

candidate边缘上报的候选事件
→
confirmed人工确认存在异常
→
processing已派发处理任务
→
closed任务完成并闭环

正常路径candidate → confirmed → closed

人工确认为异常后生成处理任务；处理结果为现场已处理、误报或无需处理时，事件可以关闭。

排除路径candidate → rejected

复核确认为正常停留、短暂通过或误报时，事件进入 rejected，但记录仍保留用于模型评估。

核心业务规则

规则必须按区域、车辆类型和作业场景配置，避免“一刀切”造成误报。

停留阈值小型车默认 5 分钟；货车建议 8 分钟；叉车建议 3 分钟。
高风险阈值超过高风险时间仍滞留，触发更高优先级提醒。
静止判断轨迹中心点持续在区域内，配合移动阈值和短时丢帧容忍。
状态增强车门打开、人员上下车、装卸、倒车等影响风险等级。
风险等级业务含义系统动作响应要求
low短暂停留或正常通行仅记录轨迹，不推送告警不需要响应
medium超时但行为不明确创建复核任务，发送站内通知30 分钟内复核
high超时且出现人员、车门、装卸等状态变化实时提醒安保 / 仓储管理员，创建处理任务5 分钟内响应
critical堵住关键通道、疑似事故或长时间滞留多渠道通知并立即升级2 分钟内确认

业务闭环机制

一个可落地系统必须有四个闭环：处理闭环、模型闭环、配置闭环、监控闭环。

处置闭环

确保每个中高风险事件都有责任人和终态。

1. 事件发现 → 任务

medium 以上事件自动创建任务，并根据风险等级设置截止时间。

2. 通知 → 已读 → 响应

站内通知为默认通道；高风险场景可扩展企业 IM、短信或电话。

3. 超时 → 升级 → 关闭

超过 due_at 仍未完成时，任务自动升级；处理结果回写事件状态。

模型与运营闭环

用真实复核结果修正规则和模型，让系统越用越准。

1. 复核 → 样本

复核结论 abnormal / normal 会生成训练样本，保留原始上下文。

2. 样本 → 标注 → 评估

按区域、车辆类型、时段分析误报和漏报，形成版本化评估报告。

3. 评估 → 阈值 / 模型更新

更新区域阈值、抽帧策略、小模型版本或 VL 提示词，并记录审计。

配置闭环：现场如何从试点走向正式运行？

先配置摄像头和区域，再用离线视频验证抽帧与阈值；然后接入一路真实 RTSP 做试运行；根据复核结果调整区域边界、静止阈值和高风险阈值；最后开启通知、升级、监控和审计，逐步扩展到多路摄像头。

监控闭环：系统如何知道自己在退化？

后端暴露进程指标和业务指标；Prometheus 持续抓取；Grafana 展示服务健康、事件上报、关键帧上传、复核速率和任务处理速率。当事件突增、上传失败增多或复核延迟变高时，需要检查边缘、网络、模型服务和人员处理效率。

隐私闭环：视频数据如何合规？

关键帧在边缘或接入层做人脸模糊；车牌按授权策略选择明文、哈希或遮盖；算法人员默认只看脱敏样本；关键帧访问、模型调用、导出和配置变更都进入审计日志。

上线验收指标

先保证业务闭环，再追求规模化和准确率提升。

≥ 90%异常停留发现率
≤ 15%误报率
≤ 10s事件识别延迟
≥ 90%上传数据量下降比例
